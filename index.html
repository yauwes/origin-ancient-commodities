📜 Tentang Proyek & Sejarah Domestikasi Manusia

🌍 APA ITU "PERADABAN SUPERMARKET"?

Supermarket modern adalah anomali terbesar dalam 300.000 tahun sejarah spesies manusia. Untuk pertama kalinya, seseorang dapat membeli kopi Etiopia, cokelat Amazon, pasta gandum Turki, saus tomat Andes, dan pisang Nusantara hanya dalam satu keranjang belanja di satu tempat.

Kenyamanan ini mengaburkan memori sejarah kita: bahwa selama 99.9% riwayat peradaban, setiap jengkal makanan terisolasi ribuan kilometer di habitat aslinya, dan manusia purba harus bertaruh nyawa menjelajahi samudra untuk mencicipi sebutir cengkeh atau sebutir lada.

🔬 Teori Pusat Asal Nikolai Vavilov (Vavilov Centers)

Pada tahun 1920-an hingga 1930-an, ahli botani dan genetika Uni Soviet terkemuka Nikolai Ivanovich Vavilov melakukan ekspedisi ke 64 negara di 5 benua untuk meneliti keanekaragaman tanaman liar. Ia menemukan bahwa tanaman budidaya tidak muncul merata di seluruh bumi, melainkan terkonsentrasi di 8 hingga 9 pusat geografis pegunungan tropis dan subtropis tertentu di mana keanekaragaman genetik liarnya paling melimpah.

⛵ Pertukaran Columbus 1492 (The Columbian Exchange)

Tahun 1492 adalah titik balik ekologi terbesar di bumi. Kontak antara Dunia Baru (benua Amerika) dan Dunia Lama (Afro-Eurasia) memicu pertukaran biologis masif tanaman, hewan, dan mikroba. Tanpa peristiwa ini:

  • 🇮🇹 Italia tidak akan mengenal tomat untuk pizza dan pasta.
  • 🇮🇩 Indonesia dan Thailand tidak akan mengenal cabai untuk sambal dan rendang.
  • 🇨🇭 Swiss dan Belgia tidak akan memiliki kakao untuk industri cokelat.
  • 🇮🇪 Irlandia tidak akan mengenal kentang.
  • 🇺🇸 Benua Amerika tidak akan memiliki sapi, kuda, kopi, gandum, atau ayam.

🚀 Panduan Deploy ke GitHub Pages (Gratis & Online)

Website ini dibangun menggunakan Pure Static Web Architecture (HTML5, CSS3, JavaScript modular, dan Leaflet via CDN). Website ini 100% siap langsung di-hosting gratis di GitHub Pages tanpa memerlukan build step server (zero-build step)!

Langkah 1: Hubungkan & Push ke Repository Anda di GitHub (@yauwes)

Buka terminal dan jalankan perintah berikut (ganti nama-repo dengan nama repository yang Anda buat di GitHub):

git remote add origin https://github.com/yauwes/nama-repo.git
git push -u origin main

Langkah 2: Aktifkan GitHub Pages di Repository

  1. Buka halaman repository Anda di https://github.com/yauwes/nama-repo.
  2. Klik menu Settings (ikon roda gigi) di tab atas.
  3. Di bilah sisi kiri, klik bagian Pages.
  4. Pada bagian Build and deployment > Source, pilih Deploy from a branch.
  5. Pilih Branch: main dan folder / (root), lalu klik Save.
✨ Selesai!
