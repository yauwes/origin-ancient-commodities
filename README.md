# 🧭 ORIGIN: Peta Komoditas Alam Peradaban Purba (Pra-Supermarket)

> **Menelusuri Peta Asal-Usul Otentik Hasil Bumi, Rempah, dan Pangan Dunia Sebelum Terjadinya Pertukaran Columbus (1492) dan Peradaban Supermarket Global.**

---

## 🌟 Tentang Proyek

Di era modern saat ini, kita hidup dalam apa yang disebut **"Peradaban Supermarket"**—sebuah peradaban di mana seseorang dapat membeli:
- **Kopi** (asli dataran tinggi Etiopia)
- **Cokelat** (asli hutan hujan Mesoamerika/Amazon)
- **Pasta gandum** (asli Hilal Subur Anatolia)
- **Saus tomat** (asli Pegunungan Andes)
- **Gula tebu** (asli rimba Papua)
- **Pisang** (asli Sundaland Nusantara)

...hanya dalam satu keranjang belanja di satu toko terdekat.

Kenyamanan ini sering membuat kita lupa bahwa selama **99.9% perjalanan sejarah manusia**, setiap komoditas alam terkurung di habitat geografis aslinya. Tidak ada orang di Eropa atau Asia yang pernah melihat cabai, jagung, atau cokelat seumur hidup mereka sebelum tahun 1492! Sebaliknya, benua Amerika sama sekali tidak memiliki gandum, sapi, kuda, kopi, atau ayam.

Website ini adalah media eksplorasi edukatif interaktif untuk mempelajari:
1. **Pusat Asal Vavilov (Vavilov Centers of Origin)**: 9 episentrum keanekaragaman botani tempat revolusi pertanian dunia pertama kali meletus.
2. **Kisah Sejarah & Mitos 45+ Komoditas Kuno**: Mengapa pala pernah bernilai lebih mahal dari emas di Eropa, bagaimana pulau New York (Manhattan) pernah ditukar dengan sebuah pulau kecil penghasil pala di Banda, dan bagaimana cengkeh Maluku ditemukan di toples kuno Mesopotamia 3.700 tahun lalu.
3. **Paradoks Hidangan Modern (The Dish Analyzer)**: Analisis komponen bahan pada hidangan seperti Rendang Minangkabau, Pizza Margherita Italia, Cokelat Swiss, Kari India, dan Kimchi Korea sebelum era perdagangan global modern.
4. **Jalur Perdagangan Kuno**: Jalur Rempah Maritim, Jalur Sutra Darat, dan Pertukaran Columbus (The Columbian Exchange 1492).

---

## 🚀 Fitur Utama

- 🗺️ **Peta Interaktif Dunia**: Didukung oleh Leaflet.js dengan 3 gaya visual: *Peta Kuno Vintage (Sepia Parchment)*, *Obsidian Gelap*, dan *Satelit Alami*.
- 📍 **45+ Komoditas Lengkap dengan Titik Koordinat Akurat**: Meliputi pangan pokok, rempah-rempah, buah, sayur, minuman stimulan, fauna domestikasi, dan material kuno.
- 🏛️ **Lapisan Pusat Asal Vavilov**: Wilayah lingkaran interaktif menandai pusat domestikasi agrikultur purba dunia.
- ⛵ **Visualisasi Jalur Perdagangan Purba**: Menampilkan Jalur Rempah Maritim, Jalur Sutra, serta rute pertukaran Dunia Baru $\leftrightarrow$ Dunia Lama pasca-1492.
- 📜 **Dossier Detail Komoditas**: Narasi mendalam mengenai sejarah botani, bukti arkeologis tertua, peradaban pertama yang membudidayakan, dan kontras dengan peradaban supermarket hari ini.
- 🍲 **Paradoks Supermarket (The Dish Analyzer)**: Menguji hidangan populer dunia dan membongkar asal benua dari setiap bahan penyusunnya.
- 🧭 **Tur Sejarah Terpandu (Guided Story Tour)**: Perjalanan naratif 8 langkah keliling dunia menelusuri titik-titik krusial agrikultur manusia.
- 🎲 **Eksplorasi Acak (Surprise Me)**: Menemukan komoditas tak terduga dengan sekali klik.

## 💻 Cara Menjalankan Secara Lokal

Website ini 100% dibuat menggunakan **Pure Web Standards (HTML5, CSS3, Vanilla JavaScript)** tanpa build tool atau kompilasi server yang rumit.

Cukup buka berkas `index.html` langsung di browser favorit Anda:
- Double click pada file `index.html`, atau
- Jalankan web server lokal ringan (opsional):
  ```bash
  # Menggunakan Python 3:
  python3 -m http.server 8080

  # Atau menggunakan npx serve (Node.js):
  npx serve .
  ```
  Lalu buka browser di `http://localhost:8080`.
